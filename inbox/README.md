# inbox — ChatGPT के भक्ति लेख यहाँ डालें

1. ChatGPT ने जो JSON दिया, उसे copy करें (```json वाले निशान समेत भी चलेगा)।
2. GitHub पर इसी folder में **Add file → Create new file** चुनें।
3. नाम लिखें, जैसे `kevat-ram.json`, JSON paste करें और **Commit changes** (सीधे main पर) दबाएँ।
4. चाहें तो ChatGPT की image भी **Add file → Upload files** से इसी नाम से डालें (`kevat-ram.png`)। न डालें तो cover अपने-आप बनेगा।

2–3 मिनट में जाँच होती है। पास होने पर फ़ाइल यहाँ से हटकर `reports/` में चली जाती है और वेबसाइट अगले घंटे में लेख publish कर देती है।
फ़ेल होने पर यहीं `<नाम>.errors.md` बनती है जिसमें कारण लिखे होते हैं — ChatGPT से वह ठीक करवाकर JSON फ़ाइल edit करें।
