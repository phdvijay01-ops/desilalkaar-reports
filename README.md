# desilalkaar-reports

देसी ललकार (desilalkaar.com) की विश्लेषण रिपोर्ट। Claude का scheduled task रोज़ एक रिपोर्ट
`reports/` में डालता है; website का cron इसे अपने-आप उठाकर draft/publish करता है।

- नियम और format: `CLAUDE.md`
- विषय: `topics.md` (किसी विषय को पहले लिखवाना हो तो "## अगला (प्राथमिकता)" में डालें)
- इतिहास: `log.md`
